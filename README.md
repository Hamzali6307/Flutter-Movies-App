# 🎬 TMDB Flutter Learning App

A Flutter application built for learning modern Flutter development using The Movie Database (TMDB) API.

## 🚀 Features

- Browse Trending Movies
- Popular Movies
- Top Rated Movies
- Upcoming Movies
- Movie Details
- Search Movies
- Movie Posters & Backdrops
- Cast & Crew Information
- Movie Genres
- Responsive UI
- Dark & Light Theme
- Error Handling
- Loading States

## 🛠 Tech Stack

- Flutter
- Dart
- TMDB REST API
- Dio / HTTP
- GetIt (Dependency Injection)
- Clean Architecture
- Repository Pattern
- MVVM / Provider / Bloc (depending on implementation)
- JSON Serialization
- Cached Network Images

## 📚 Learning Objectives

This project was created to practice:

- REST API integration
- JSON parsing
- State management
- Dependency Injection using GetIt
- Repository Pattern
- Clean Architecture
- Reusable Widgets
- Navigation
- Responsive UI
- Error Handling
- Code Organization
- Flutter Best Practices

## 📂 Project Structure

```
lib/
 ├── core/
 ├── data/
 ├── domain/
 ├── presentation/
 ├── services/
 ├── models/
 └── main.dart
```

## 📦 API

This project uses The Movie Database (TMDB) API.

https://developer.themoviedb.org/

## 🎯 Purpose

The main goal of this project is to improve Flutter development skills by implementing production-level architecture and best practices while working with a real-world API.

## ⚠️ Disclaimer

This project is for educational purposes only and uses data provided by TMDB.
